# 🌐 GLOBAL POOL COMBINATOR (해외 축구 토토 14경기 수학적 조합기)

해외 토토 및 축구 승무패 14경기 대상 **2등(13경기) 100% 보장 수학적 압축 조합기** 독립 프로젝트입니다.

---

## 🚀 빠른 실행 방법

### 방법 1 (가장 간편): `run.bat` 더블 클릭
* 바탕화면의 `해외조합기` 폴더 안의 `run.bat` 파일을 더블 클릭하면 자동으로 로컬 서버(포트 `7777`)가 구동되고 브라우저가 열립니다.

### 방법 2: 브라우저로 직접 열기
* `index.html` 파일을 크롬(Chrome)이나 엣지(Edge) 브라우저로 직접 열어도 100% 정상 작동합니다.

---

## ⚡ 핵심 기능 및 수학적 보장

1. **2등(13경기) 100% 보장 독점 특허출원 압축 엔진 (Patent Pending KR 10-2026-0205596)**
   * 복식/삼식을 아무리 많이 마킹해도 독점 특허출원 압축 엔진을 통해 **비용을 80%~90% 이상 절감**하면서, 마킹 범위 내 모든 결과에 대해 최소 2등 당첨을 100% 보장합니다.
2. **글로벌 표기법 완벽 지원**
   * `1 / X / 2` (유럽 및 해외 북메이커 표준)
   * `W / D / L` (영미권 표준)
   * `승 / 무 / 패` (국내 표준)
3. **다국어 지원**
   * 🇰🇷 한국어 / 🇬🇧 English 원클릭 전환
4. **조건부 고급 필터링**
   * 무승부(X) 개수 범위 필터
   * 홈승(1) / 원정승(2) 개수 범위 필터
   * 최대 연속 동일 부호 제한 필터
5. **원클릭 데이터 내보내기**
   * 슬립 전체 클립보드 복사 (해외 베팅 사이트 빠른 마킹용)
   * TXT 다운로드
   * CSV / Excel 다운로드
   * 경기별 부호 출현 통계 매트릭스 실시간 집계
